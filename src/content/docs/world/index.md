This part shows how Strata holds a game's world in memory, runs it and keeps it on disk. The first pages explain the entity, the component and the system, then the scene with its hierarchy and fixed steps. The turning point is reflection, one description of each component that files, commands and the Inspector read. After it the pages follow the data into scene documents, prefabs, sub-scenes and settings, and a tutorial adds a component. At the end you can predict what a frame does to a scene and add a component that every tool handles.
