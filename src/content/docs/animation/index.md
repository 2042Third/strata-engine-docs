This part follows one character from its model file to the screen. It starts with why a game stores motion as keys on a skeleton, then builds the skeleton, the clips and the skinning, and the importer that reads them. The turning point is the state machine, after which blending, time, events and root motion let a controller move a character. The last pages cover the Animation system, unseen characters, the editor's previews and what Strata lacks. At the end you can compute a pose, a skinned vertex and a cross-fade, and trace a fault to its page.
