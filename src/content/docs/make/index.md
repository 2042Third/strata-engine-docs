This part teaches you to make a game with Strata and to ship it. It starts with the editor, scenes, assets, materials and light, and then you write your first script. The turning point is the game loop: from there scripts read input, move bodies and play sound, and Coin Run ends in an exported game. Later pages add the tools of a larger game, from timers, patterns and menus to the look, speed and automated tests. At the end you can plan, build, test and export a small game.
