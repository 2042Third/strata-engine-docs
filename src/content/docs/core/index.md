This part teaches how a Strata program is built and what it does while it runs. It starts with the engine's map, a first change, its conventions, reading its code and the path from `main` to the first frame. From the frame loop, its turning point, the pages follow one frame outward: time, events, modules, registries and jobs. The last pages reach the operating system and files, then measuring, debugging and the engine's math. At the end you can find your way in the code, change it with a test, predict a frame's work and diagnose a fault.
