# Notes: make/designing-a-game

## New terms

- playtest: a session in which a person who has not seen the game plays it while the maker watches and stays silent; home this page; aliases playtests, play testing.
- core loop: the short cycle of action, result and reward that a player repeats for the whole game; home this page.
- scope (of a game): the amount of game a maker commits to make: features, content and polish; qualified, apart from the scope of a name in code.
- cut list: a list that sorts features into must, should and could.
- prototype: a rough, quick version of a game made to answer one question.
- grey box: a game built in the engine from plain shapes with no art.
- vertical slice: one small part of the game made to the quality of the finished game.
- one-paragraph design: a few sentences, written before the work, that fix what the player does, the loop, win and loss, controls and cuts.
